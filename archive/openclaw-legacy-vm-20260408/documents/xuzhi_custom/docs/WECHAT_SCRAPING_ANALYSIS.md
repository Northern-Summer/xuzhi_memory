# 微信公众号文章抓取方案分析 | 2026-04-01

## 现状调查

### 文章中提到的方案状态

| 方案 | 状态 | 说明 |
|------|------|------|
| 1. WeChat-Article-Exporter | ✅ 有效 | 2025年3月还在更新 |
| 2. PC 微信 Hook | ⚠️ 风险高 | 可能违反微信条款，账号有封号风险 |
| 3. 公众平台 + Selenium | ✅ 有效 | 需要公众号权限 |
| 4. 搜狗微信搜索 | ⚠️ 部分有效 | 能搜索，但无法获取全文 |

### 2025年最新结论

根据 CSDN 文章（2025年）：

**已失效**：
- ❌ 搜狗接口 - 早就不更新了
- ❌ 直接 request - 微信各种认证搞不定
- ❌ Selenium 自动化 - 拿不到 HTTP 接口
- ❌ mitmproxy 代理 - 微信文章不走 HTTPS 了

**仍然有效**：
- ✅ RPA 方案（pyautogui）- 模拟用户操作
- ✅ WeChat-Article-Exporter - 通过微信客户端

## 当前系统状态

### 我们已有的工具

```
~/.openclaw/workspace/wechat_scraper.py
~/.openclaw/workspace/wechat_search.py
```

**功能**：
- ✅ 搜索公众号文章（通过搜狗）
- ❌ 获取文章全文（搜狗只返回标题和链接）

**测试结果**：
```
============================================================
📰 微信公众号搜索: Claude Code
============================================================

   1. [2026-03-31] @未知
      Claude Code生态发展很快,头部项目已经有10万star了...
      → https://weixin.sogou.com/link?url=...
```

**问题**：只能获取标题，无法获取文章内容。

## 解决方案

### 方案 1：WeChat-Article-Exporter（推荐）

**项目地址**：https://github.com/wechat-article/wechat-article-exporter

**特点**：
- 在线批量导出微信公众号文章
- 支持内嵌音视频导出
- 100% 还原文章样式
- 支持私有部署

**使用方式**：
1. 访问 GitHub 下载预编译版本
2. 登录 PC 微信
3. 选择公众号，批量导出

**优点**：
- 无需编程，直接使用
- 支持图片、音视频、评论
- 可私有部署

**缺点**：
- 需要手动登录微信
- 只能抓取你关注的公众号

### 方案 2：RPA 方案（pyautogui）

**原理**：模拟用户操作，自动点击、滚动、截图

```python
import pyautogui
import time

# 1. 搜索指定公众号
# 2. 打开公众号文章列表
# 3. 逐个点击文章
# 4. 截图/OCR 提取内容
# 5. 保存到文件
```

**优点**：
- 理论上万能
- 跨平台

**缺点**：
- 开发成本高
- 需要处理各种边界情况

### 方案 3：公众平台接口

**适用场景**：有自己的公众号

**原理**：
1. 登录微信公众平台
2. 使用 Selenium 模拟操作
3. 获取文章列表和内容

**优点**：
- 合法合规
- 可抓取历史文章

**缺点**：
- 需要公众号权限
- 只能抓取有限范围

## 建议实施

### 短期方案（立即可用）

1. **手动使用 WeChat-Article-Exporter**
   - 下载：https://github.com/wechat-article/wechat-article-exporter/releases
   - 登录微信后批量导出

2. **增强现有搜索功能**
   - 保持 `wechat_search.py` 用于搜索
   - 添加 `--export` 参数，输出链接列表
   - 手动在浏览器中打开阅读

### 长期方案（需要开发）

1. **集成 WeChat-Article-Exporter API**
   - 部署到本地服务器
   - 提供 REST API 供 Agent 调用

2. **RPA 自动化**
   - 开发 pyautogui 脚本
   - 集成到 OpenClaw 技能系统

---

## 结论

**问题**：微信公众号文章无法直接通过 HTTP 抓取全文

**原因**：微信有严格的反爬机制，文章内容需要微信客户端才能查看

**最佳实践**：
- 搜索：使用现有的 `wechat_search.py`
- 全文：使用 WeChat-Article-Exporter 手动导出
- 自动化：考虑 RPA 方案或公众平台接口
