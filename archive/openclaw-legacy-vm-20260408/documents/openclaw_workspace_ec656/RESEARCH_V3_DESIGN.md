# 研究系统 v3 — 框架融合版

## 设计原则

**取最大并集，最优雅实现**：
- MetaClaw：双时间尺度 + 技能演化
- Echo：Train-on-Future + 预测校准
- HyperAgent：Session End 自演化
- 7 Agents：分工协作

---

## 研究闭环架构

```
┌─────────────────────────────────────────────────────────────┐
│                    研究问题（固定）                          │
│   《粒度、框架与规范：多智能体系统失败的认识论根源》          │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  文献采集（MetaClaw Fast Adaptation）                        │
│  - arXiv API 自动搜索                                        │
│  - Semantic Scholar 补充（rate limit 后）                    │
│  - 相关性/质量双评分                                         │
│  - 输出：文献库 JSON                                         │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  深度阅读（Multi-Agent 分工）                                │
│  - Xi: 哲学文献（框架问题、规范语义学）                       │
│  - Phi: 技术文献（多智能体系统）                             │
│  - Delta: 方法论文献（论证结构）                             │
│  - 输出：读书笔记 + 原文引用 + 页码                          │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  论证构建（可溯源 + 可验证）                                  │
│  - 每个 claim 有 evidence_id                                 │
│  - 每个 evidence 有 quote + page                             │
│  - 输出：Argument JSON                                       │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  同行评审（Echo 预测校准）                                    │
│  - 第三方质疑（DeepSeek）                                    │
│  - 预测引用准确性                                            │
│  - 预测论证强度                                              │
│  - 输出：评审报告                                            │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  修改迭代（HyperAgent 自演化）                                │
│  - Session End 强制执行                                      │
│  - 技能库更新（g → g+1）                                      │
│  - 输出：下一版初稿                                          │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  投稿（公开发表）                                            │
│  - LaTeX 格式化                                              │
│  - NeurIPS Workshop                                          │
│  - 输出：投稿版                                               │
└─────────────────────────────────────────────────────────────┘
                              ↓
                    MetaClaw 技能演化
                    （从失败中学习）
                              ↑
                              └──────────────────────┘
```

## 框架融合映射

| 研究阶段 | 框架 | 机制 |
|---------|------|------|
| 文献采集 | MetaClaw | Fast Adaptation（秒级更新文献库） |
| 深度阅读 | Multi-Agent | Xi/Phi/Delta 分工 |
| 论证构建 | 无 | 可溯源/可验证原则 |
| 同行评审 | Echo | Train-on-Future（预测校准） |
| 修改迭代 | HyperAgent | Session End 自演化 |
| 投稿 | 无 | 公开发表标准 |

## Session End 自演化流程（HyperAgent）

```
Session 结束前执行：
1. 检查本次 session 的失败操作
2. 分析失败原因
3. 提取新技能（如果有）
4. 更新技能库（g → g+1）
5. 写入 evolution_log
6. 提交 git
```

---

## Echo 校准机制

```
预测 → 验证 → 更新

预测：
- 引用准确性预测（能否找到原文？）
- 论证强度预测（能否经得起质疑？）

验证：
- 实际查找原文
- 实际接受评审

更新：
- 校准分数
- 调整预测模型
```
