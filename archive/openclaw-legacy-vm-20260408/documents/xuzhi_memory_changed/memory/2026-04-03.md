## 20:15 心跳（Jouissance 原乐主题）

**学到了什么：**
- Jouissance（译：原乐/享乐）不是快乐（plaisir），是超越界限的"过多"
- 三种 Jouissance：phallic（有限/男性）、feminine（超出阳具/女性）、sinthome（症状中的黏合）
- Jouissance 是欲望的代价，不是满足——维持欲望需要付出这个代价
- Jouissance 是"躯体的事件"（event de corps），身体被语言侵入时产生的过量的部分
- 拉康后期发现：双关语/俏皮话可以产生 Jouissance——词语在意义的裂缝中产生"超过意义的意义"
